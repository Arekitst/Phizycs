РУХ СТАЄ СТРУМОМ

ЗАПУСК ПРЕЗЕНТАЦІЇ
Відкрийте index.html у браузері. Це готовий статичний проєкт: окремі HTML, CSS і JavaScript файли. Сервер та інсталяція програм не потрібні.

ТЕКСТ ЗАХИСТУ НА ДВОХ
Відкрийте «Читати-текст-захисту.html» — повний текст із великим шрифтом, зміною розміру, навігацією за 7 частинами, автопрокруткою, повноекранним режимом і кнопкою друку. Версія .txt поруч зручна для копіювання чи редагування. Спочатку виступає Устименко Маріанна (частини 01–03), потім Горбунов Артемій (04–07).

СТРУКТУРА
index.html                       інтерактивна сторінка-презентація
css/style.css                    темний адаптивний дизайн та анімації
css/visual-fallback.css          повідомлення, якщо фото не завантажилося
js/app.js                        перемикання режимів і Three.js модель
Читати-текст-захисту.html         окрема сторінка-читалка для двох доповідачів
Текст-захисту-2-учасники.txt      звичайний текст промови

УПРАВЛІННЯ ПРЕЗЕНТАЦІЄЮ
Прокручуйте сторінку. У розділі «Розбираю по шарах» прокрутка роз'єднує деталі 3D-моделі двигуна. У розділі про енергію перемикайте «Двигун / Генератор». У фото справжнього двигуна можна обирати номери деталей.

ІНТЕРНЕТ
Для фото, шрифтів і анімації 3D-моделі потрібен інтернет: використовуються Wikimedia Commons, Google Fonts, Three.js та GSAP. Сторінка захисту на двох працює повністю локально.
